# Data / 数据

## English

No MORPH or FG-NET images are distributed here. Place metadata CSV files in this directory or point the YAML configuration to another location. Required fields are `path`, `person_id`, and `age`; an optional `split` field may contain `train`, `val`, or `test`.

## 中文

本仓库不分发MORPH或FG-NET原始图像。可将元数据CSV放在此目录，或在YAML配置中指定其他路径。必需字段为`path`、`person_id`和`age`；可选字段`split`可取`train`、`val`或`test`。
