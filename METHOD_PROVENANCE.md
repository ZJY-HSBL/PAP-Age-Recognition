# Method Provenance / 方法来源与归属

## English

This codebase is an independent software implementation of the PAP (Personalized Aging Pattern) facial-age-estimation method described by Huiying Zhang, Wenshun Sheng, and Haoyi Xie in *Journal of Guangxi University (Natural Science Edition)*, 2025, Vol. 50 No. 3, pp. 635–644, DOI: 10.13624/j.cnki.issn.1001-7445.2025.0635.

The repository code, engineering structure, configuration system, tests, CLIs, and implementation decisions are newly written for this project. The underlying PAP method and the reported reference results should be attributed to the original authors. Do not present the method itself as newly invented by the repository owner.

## 中文

本代码库是对PAP（Personalized Aging Pattern，个体老化模式）人脸年龄识别方法的独立软件实现。该方法由张会影、圣文顺、谢昊译发表于《广西大学学报（自然科学版）》2025年第50卷第3期，页635–644，DOI：10.13624/j.cnki.issn.1001-7445.2025.0635。

仓库中的代码、工程结构、配置系统、测试、命令行工具及具体实现细节均为本项目重新编写；PAP方法本身以及原始报告结果应归属于原作者，不应将该方法本身表述为仓库所有者原创提出。
