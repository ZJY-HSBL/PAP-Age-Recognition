# Results Guide / 结果说明

## English

`assets/reference_mae.csv` stores the reported comparison values for AGES, ODFL, RAE, and PAP. These are **reference values, not outputs generated by this repository**. Your actual run is written to `runs/<dataset>/evaluation/metrics.json` and should be reported separately.

A faithful comparison requires the same dataset version, preprocessing, split policy, feature extractor training regime, and sequence construction. The most important diagnostic is not only final MAE but also the entire CS(0…10) curve.

## 中文

`assets/reference_mae.csv`保存AGES、ODFL、RAE与PAP的报告对比数值。这些是**参考值，不是本仓库实际训练产生的结果**。你自己的实验结果会写入`runs/<dataset>/evaluation/metrics.json`，应与参考值分开表述。

要进行严格比较，需要保持数据集版本、预处理、划分策略、特征提取器训练过程以及个体序列构建一致。除最终MAE外，还应同时检查完整的CS(0…10)曲线。
